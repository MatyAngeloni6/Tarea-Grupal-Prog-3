# 🚀 Parking CRM 

### 📝 Descripción
Sistema de gestión para la administración de cocheras que permite controlar el alquiler de espacios por día, semana o mes. El software centraliza el registro de vehículos, la disponibilidad de lugares en tiempo real y el seguimiento de los vencimientos de cada cliente.
